# Privacy Policy

Personal OAuth client for the Google Workspace MCP server.

- It requests Workspace scopes (Gmail, Drive, Docs, Sheets, Slides, Calendar, Tasks) only so its single operator can read and edit their own data.
- OAuth credentials and tokens stay on the local machine at ~/.config/workspace-mcp, owner-only permissions.
- No data is collected, transmitted, shared or sold. There is no server component.
- Access can be revoked at https://myaccount.google.com/permissions.
